# River6.vue - 生命之河：全球战争频次与伤亡趋势 (1946-2024)

## 组件概述

`River6.vue` 是一个基于 Vue 3 和 ECharts 的主题河流图（ThemeRiver）可视化组件，用于展示 1946 年至 2024 年间全球战争频次与伤亡趋势的动态变化。

## 功能特性

- **主题河流图展示**：使用 ECharts 的 `themeRiver` 类型，直观呈现不同强度冲突随时间的演变趋势
- **双时期数据展示**：
  - **1988年及之前**：展示高强度战争与低强度冲突的汇总数据
  - **1989年及之后**：展示按伤亡人数细分的详细分类数据
- **智能悬浮提示**：鼠标悬停时显示当前年份的详细冲突数据，支持不同时期的差异化展示
- **响应式设计**：监听窗口 resize 事件，自动调整图表尺寸
- **深色主题 UI**：采用现代化的深色配色方案，适合数据可视化大屏展示

## 数据分类

组件将战争/冲突按伤亡人数分为以下类别：

### 高强度战争

- 伤亡 50000+
- 伤亡 5000~50000
- 伤亡 900~5000

### 低强度冲突

- 伤亡 0~300
- 伤亡 300~1000

## Props

| 属性名      | 类型      | 默认值 | 说明                                               |
| ----------- | --------- | ------ | -------------------------------------------------- |
| `rawData` | `Array` | `[]` | 外部传入的原始数据，组件会监听其变化并重新渲染图表 |

## 数据结构

组件期望的数据格式为对象数组，每个对象包含以下字段：

```javascript
{
  year: Number,              // 年份 (1946-2024)
  high_intensity_50000_plus: Number,    // 伤亡50000+的高强度战争数量
  high_intensity_5000_50000: Number,    // 伤亡5000~50000的高强度战争数量
  high_intensity_900_5000: Number,      // 伤亡900~5000的高强度战争数量
  intensity_level_2_count: Number,      // 高强度战争汇总计数
  intensity_level_1_count: Number,      // 低强度冲突汇总计数
  low_intensity_0_300: Number,          // 伤亡0~300的低强度冲突数量
  low_intensity_300_1000: Number        // 伤亡300~1000的低强度冲突数量
}
```

## 数据来源

组件默认从 `/result2.json` 加载数据，该文件应放置在项目的 `public` 目录下。

## 颜色配置

| 类别                         | 颜色        |
| ---------------------------- | ----------- |
| 高强度战争（伤亡50000+）     | `#DC143C` |
| 高强度战争（伤亡5000~50000） | `#8B0000` |
| 高强度战争                   | `#AA3118` |
| 高强度战争（伤亡900~5000）   | `#CD5C5C` |
| 低强度冲突（伤亡0~300）      | `#FFD700` |
| 低强度冲突                   | `#F0A65A` |
| 低强度冲突（伤亡300~1000）   | `#FFA500` |

## 依赖

- [Vue 3](https://vuejs.org/)
- [ECharts](https://echarts.apache.org/)

## 使用示例

```vue
<template>
  <River6 :rawData="warData" />
</template>

<script setup>
import River6 from './components/RiverMap/River6.vue';
import { ref } from 'vue';

const warData = ref([
  {
    year: 2000,
    high_intensity_50000_plus: 2,
    high_intensity_5000_50000: 5,
    // ... 其他字段
  }
]);
</script>
```

## 样式变量

组件使用 CSS 变量定义主题色：

| 变量名               | 默认值      | 说明           |
| -------------------- | ----------- | -------------- |
| `--bg-global`      | `#12141C` | 全局背景色     |
| `--bg-container`   | `#1E222D` | 图表容器背景色 |
| `--text-primary`   | `#E2E8F0` | 主要文字颜色   |
| `--text-secondary` | `#94A3B8` | 次要文字颜色   |
| `--border-color`   | `#334155` | 边框颜色       |

## 注意事项

1. 组件会在挂载时自动从 `/result2.json` 加载数据，如果传入 `rawData` prop，则会优先使用传入的数据
2. 图表容器需要足够的空间展示，建议父容器高度不低于 400px
3. 组件使用 `scoped` 样式，不会影响全局样式
