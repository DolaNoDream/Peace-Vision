| 英文字段名 | 中文字段名 | 数据类型 | 核心含义与编码说明 | 数据特征 |
| --- | --- | --- | --- | --- |
| conflict_id | 冲突唯一 ID | 整数  | UCDP 数据集核心主键，唯一标识每一场冲突，用于关联冲突表与死亡表 | 取值范围：100-9999，无重复 |
| year | 冲突发生年份 | 整数  | 记录冲突发生的具体年份，覆盖 UCDP 全时间周期 | 取值范围：1946-2024 |
| incompatibility | 冲突核心议题 | 整数  | 冲突爆发的核心诱因，编码规则：1 = 领土争端；2 = 政权争夺；3 = 领土 + 政权双重争端 | 取值：1/2/3，以 1/2 为主 |
| type_of_conflict | 冲突类型 | 整数  | 以下四种冲突类型之一：1=系统外冲突（发生在国家与其领土之外的非国家组织之间）；2=国家间冲突；3=国内冲突；4=国际化国内冲突（A方始终为政府；B方始终为一个或多个反叛组织；有外国政府派遣军队介入）。 | 取值：1/2/3/4 |
| intensity_level | 年度冲突强度等级 | 整数  | 按年度死亡人数划分的冲突强度，编码规则：1 = 次要冲突（25-999 人）；2 = 战争（≥1000 人） | 取值：1/2，分布均衡 |
| region | 地理区域 | 整数  | 冲突所属的宏观地理区域，编码规则：1 = 欧洲；2 = 中东；3 = 亚洲；4 = 非洲；5 = 美洲 | 取值：1-5，非洲 / 亚洲占比高 |
| gwno_loc | 冲突地国家代码 | 整数  | Gleditsch-Ward 国家地理编码，用于匹配世界地图边界（核心地图关联字段） | 取值范围：2-990，对应全球国家 |
| gwno_a | A冲突方国家代码 | 整数  | Gleditsch-Ward 国家地理编码，用于匹配世界地图边界（核心地图关联字段） |     |
| location | 冲突归属国家 | 字符串 | 冲突主权归属的国家名称（非实际交战地点，为官方主权国） | 如 “China”“Ukraine”，无空值 |
| side_a | A 方名称 | 字符串 | 冲突中的主要一方，通常为政府、主权国家或官方认可的政权 | 如 “Government of Syria”，无空值 |
| side_a_id | A方ID | 整数  |     |     |
| side_b | B 方名称 | 字符串 | 冲突中的对立一方，通常为反政府武装、反对派或他国势力 | 如 “Rebel Groups”，无空值 |
| side_b_id | B方ID | 整数  |     |     |
| start_date | 冲突开始日期 | 字符串 | 冲突首次爆发的日期，格式为 “YYYY-MM-DD”，精度因数据来源不同有差异 | 如 “1950-06-25”，无空值 |
| ep_end |     | 整数  | 该虚拟变量用于编码冲突在次年是否处于非活跃状态，从而确定冲突是否结束。若冲突在后续一年（或数年）内处于非活跃状态，该变量值为1；否则为0。 | 取值为1/0 |
| ep_end_date | 冲突阶段结束日期 | 字符串 | 冲突某一阶段（如停火、协议终止）的结束日期，空值表示冲突持续或未记录 | 部分为空，格式同 start_date |
| territory_name | 领土名称 | 字符串 | 冲突发生的领土名称（前提是争议涉及领土问题）。 |     |
| cumulative_intensity | 累积强度 | 整数  | 该变量考虑了冲突的时间维度。它是一个虚拟变量，用于编码冲突自爆发以来是否已导致超过1,000名战斗相关死亡。对于1946年之前的冲突，该变量不计入此前年份的死亡人数。只要冲突在一段时间内未导致超过1,000名战斗相关死亡，其编码即为0；一旦冲突达到这一阈值，其编码即为1。 | 取值为0/1 |
| total_deaths | 总伤亡人数 | 整数  | 1989年之后的死亡数据是基于UCDP的bestdeath，并合并同一conflict_id的统计数据；1989年之前的死亡数据由燕奕博进行查阅后补充 |     |
| war_name | 战争名 | 字符串 | 由燕奕博同学进行补充，查询每场战争的通用名称 |     |
| war_description | 战争描述 | 字符串 | 由燕奕博同学进行补充，查询中文互联网后给出对于战争的简短描述 |     |
