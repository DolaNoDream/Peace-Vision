# 整体规范文档

## 一、尺寸与边距统一规范（CSS 强制规范）

1\. 外层容器宽度（所有模块必须遵守）

宽度：width: 100%

最大宽度：max-width: 1400px

居中：margin: 0 auto

2\. 各模块高度规范

热力图模块：height: 60vh 或固定 550px

河流图模块：height: 450px

桑基图模块：height: 600px

3\. 模块间距

模块与模块之间：margin-top: 40px

页面最顶部、最底部保留：margin: 20px 0

4\. 图表内部 grid 留白统一（Echarts 通用）

left: '5%',

right: '5%',

top: '8%',

bottom: '10%'

保证三张图左右边缘完全对齐。

### 2.模块一：热力图——"时空烙印" 高级配色

#### 2.1 热力叠加层（牺牲/强度）——单色系细腻渐变

采用**单色系（橙红→深红）渐变**，避免多色系造成的认知混乱。共7级，足够覆盖bd_best伤亡范围：

| **等级** | **伤亡范围(bd_best)** | **颜色名称** | **Hex码** | **色值** |
| --- | --- | --- | --- | --- |
| 1级  | 0   | 极浅贝色 | #ECE8E3 |     |
| 2级  | 1-99 | 杏色  | #FDE4C5 |     |
| 3级  | 100-999 | 沙色  | #F8B87A |     |
| 4级  | 1,000-9,999 | 橘黄  | #E66B22 |     |
| 5级  | 10,000-49,999 | 朱红  | #BD2E1F |     |
| 6级  | 50,000-199,999 | 深绯  | #96281B |     |
| 7级  | ≥ 200,000 | 勃艮第红黑 | #731513 |     |

#### 2.2 散点层（冲突频次）——使用互补色增强可读性

由于底层热力层是红橙色系，顶层散点采用**冷色调**的蓝灰色，增强视觉分离感：

| **冲突数量** | **颜色** | **Hex码** |
| --- | --- | --- |
| 1-5次/年 | 雾蓝  | #ABADB3 |
| 6-15次/年 | 石板蓝 | #7A8B99 |
| 16-30次/年 | 深海蓝 | #4A5D6B |
| ≥31次/年 | 暗夜蓝 | #1C2D3D |

💡 这种冷暖对比让冲突高频区域在热力图中**跳出**成为视觉焦点，同时保持了整体协调性。
